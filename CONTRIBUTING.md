# Contributing

Thank you for your interest in contributing to this project!

Contributions are welcome for improving feature extraction, image preprocessing, object detection performance, documentation, or visualization.

---

## Clone Repository

```bash
git clone https://github.com/<your-username>/Cricket-Object-Detection.git
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Notebook

```bash
jupyter notebook
```

Open:

```
Cricket_Object_Detection.ipynb
```

---

## Contribution Guidelines

- Follow PEP8 coding standards.
- Keep notebooks clean and organized.
- Document new features.
- Test code before submitting.
- Update README if functionality changes.

---

## Pull Requests

Please include:

- Description of changes
- Motivation
- Screenshots (if applicable)
- Testing details

Thank you for helping improve this project!
